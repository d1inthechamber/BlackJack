# Audio credits

Casino Chaos includes short recorded human reactions. All three files were
converted to mono Ogg Vorbis and loudness-normalized for in-game playback.

- `dealer_laugh.ogg`: excerpt from “Male Laughter.wav” by Eneasz,
  [Freesound 119459](https://freesound.org/people/Eneasz/sounds/119459/),
  dedicated to the public domain under CC0. The packaged file uses a 1.8-second
  excerpt from the ESC-50 copy.
- `dealer_groan.ogg`: “Grunts of Male Death and Pain” by
  thebardofblasphemy,
  [OpenGameArt](https://opengameart.org/content/grunts-male-death-and-pain),
  dedicated to the public domain under CC0. The packaged file was normalized
  and converted from `death.wav`.
- `dealer_grunt.ogg`: “Grunt” by n3b,
  [OpenGameArt](https://opengameart.org/content/grunt), licensed under
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The packaged file
  was normalized and converted from `grunt.wav`.

These reactions are used only for brief laugh, frustration, and tension cues.
They never loop and respect the persistent Dealer Voices setting.
